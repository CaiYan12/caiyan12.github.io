After · artifact 自证

capture
↓
artifact module：版本 + 每页静态数 + 四态计数 + 完整性

写入与读取共用同一 schema；旧格式必须显式拒绝。

↓
diff：先校验覆盖与对称性，再比较差异
incomplete / 版本不符 / 状态数不对称 → 响亮失败

Problem

采集失败时，artifact 仍看起来合法；测试门禁无法表达“覆盖不完整”，因此可能把没测到误当成没变化。

Solution

把 artifact 的格式、覆盖与兼容判定收进一个窄 interface，让 capture 与 diff 两个真实 caller 共用；失败要么使 capture 非零，要么留下 diff 必拒的 incomplete artifact。

Wins

  • leverage：两个 caller 共用一套格式契约
  • locality：覆盖失败只在 artifact 一处判定
  • 测试直接构造缺状态、版本漂移、非对称
  • 后续 runtime 改动获得可信 UI 证据

UI 约束：不碰任何页面、CSS、渲染产物；只改脚本与测试。ADR：不重开 ADR 0011 的层策略。

常驻模块不进入页面会话：拉绳挂件、头部微言轮播仍按既有一次性初始化。

Problem

“这个页面级功能何时算活、何时必须死”没有单一 interface；旧 interval 与监听器可越过 swap 存活，真实 bug 藏在调用处而非纯函数里。

Solution

在既有 pagefindReady → runtimeTable/runtimeHooks seam 内加深页面会话 owner：各功能只声明页面级 start / stop，不再自行监听页面加载事件；先迁 Slideshow 与字号，再迁 tabs 与 TagCloud3D。

Wins

  • leverage：一个生命周期 interface 覆盖多个功能
  • locality：timer / listener / 异步收尾集中清理
  • 真实 Swup 行为可测，不依赖内部布尔量
  • 旧 DOM 不再被后台 interval 改写

UI 约束：不改 DOM、样式、轮播间隔、swap 1–8 次序、字体功能与 reduced-motion。ADR：与 0004/0007/0008/0010/0011/0012 无直接冲突，但必须保留 ADR 0008 的目录换页时序。

Problem

同一可画性知识跨 seam 泄漏；修一侧的晚到事件或监听清理，另一侧不会自动受益。

Solution

先做等价性 spike，只抽“单次结算 + 可画判断 + 清理”的内部 module；预载仍拥有 12s 与候选轮换，交叉淡入仍拥有 1.5s、临时层与回滚。

Wins

  • 两个真实 caller 共用 readiness
  • 晚到事件与监听清理获得 locality
  • 保留两种事务，不制造多参数 module
  • 现有测试矩阵即可验证，不新增生产出口

UI 约束：不改视觉、超时时长、临时层顺序、交叉淡入与回滚语义。ADR：与 ADR 0010 的挂件行为无冲突；不得把随机背景选图合并进来。

Top recommendation

先修测量仪，再动页面生命周期

首选 01 · 样式指纹自证覆盖。它对线上 UI 零影响，却决定后续所有“UI 没变”结论是否可信；当前 CDP 失败可静默产出看似合法的 artifact。修完它，再做生产 leverage 最大的 02 · 页面级 runtime 会话，用同一套可信门禁守住真实 Swup 往返。

执行顺序：01 → 02 → 03 → 04 → 05。03 是 05 的前置；04 可与 02 解耦推进。任何阶段出现可见差异，停止并交站长裁决。
