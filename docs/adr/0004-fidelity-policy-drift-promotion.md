# 还原度政策：原版优先，但更优的偏离转正为基线

本站的顶层契约是「视觉必须还原 Emlog Colorful 原版」。在 T1 审计里这条契约与无障碍正面撞上：`#999aaa` **就是原版的次要文字色**（`docs/reference/colorful-original.css:251/:183/:334/:446-479`），在白色卡片上只有 2.78:1；而我们某次改动里引入的 `#666`（`global.css:5070-5078`）是偏离原版的「漂移」，却有 5.74:1。我们决定把政策写成三条，而不是笼统的「原版优先」：

1. **原版优先**——凡取证证明当前值与 `colorful-original.css` 一致的，不动，即使它看起来不一致或不现代。
2. **无障碍硬失败无条件修**——对比度不达标、禁缩放、键盘不可达这类，无论是否原版值。
3. **更优的偏离转正为基线**——当我们的偏离在可达性或一致性上优于原版时，保留偏离并记录在案；否则下一轮审计会把它当漂移「修回原版」，等于把已变好的地方改差。

**Considered options**：严格回原版（要为还原而主动降低可读性）；内部一致优先（等于放弃顶层契约）；逐案裁决（同类情形会反复重开，且没有可继承的结论）。

**Consequences**：本站的「基线」从此是 *原版 + 已转正偏离集*，不是原版本身。已转正的第一例是全站次要文字统一 `#666`（取代原版 `#999aaa`）。反过来，被本政策保护为「不是缺陷」的有：正文行高 24px 与 `#content` 25px 并存（原版 `:304` 与 `:222` 就是两个值）、`.post-context h4` 无上边距（原版 `:305` 亦无）、标签药丸 20px 命中高与六色轮换（原版 `:162` 逐字节相同）、幻灯片指示点 10×10（原版 `:716`）。
