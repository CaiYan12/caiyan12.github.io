# 0014：六类不生成盒子的标签不参与「可见差异」判定

## 背景

`diff` 的比对键是「状态前缀 + 全部兄弟元素序号」，且元素增删一律记「可见」。两条叠加，删掉一个不生成盒子的 `<script>` 会同时制造两类假差异：脚本自己少一行，以及它之后所有兄弟元素的序号整体前移，成批变成 `REMOVED` / `ADDED`。

2026-11-10 撞上了：F2 把四个页面级功能的内联脚本迁进共享 chunk，真实差异只有 **18 个 `<script>`**，工具却报 **12/23 页、2,365 条**，把「结构性搬动」误报成「全站样式变化」。

这类假阳性比漏报更伤：它会让人开始怀疑判据本身，然后在下一次真红灯前先选择放行。

## 决定

**一、六类标签不参与比对**：`script` / `style` / `link` / `meta` / `noscript` / `template`。判定收在 `NON_RENDERING_TAGS` 一个常量里，不散落在调用点。

**二、采集端不动。** artifact 里仍保留全部行；`elements`、`staticLines`、sha、四态计数仍按采集正文校验。剔除只发生在 `load()` 生成的比对副本上，不影响完整性判定。

**三、未知标签、空值、非字符串一律当渲染元素**（宁严不宽）。`img` / `input` / `br` 这类会生成盒子或被布局计数的元素不在其列。

**四、只解决「不渲染元素增删」，不解决「真实重排导致路径键漂移」。** 后者仍先由 `bag` 判成 `reorder-only`，`bag` 也不相等时才逐条比。

**五、剔除必须可见。** 汇总行打印两侧各剔除了多少条（本次 199 / 181），不做无声过滤。

## 被否掉的方案及理由

**从比对键里删掉兄弟序号。** 否掉：那会连真实重排一起抹掉，等于把「元素挪位」这一类差异整体放行。这正是本仓库付过代价的地方——键里的序号既能造假阳性，也是重排的唯一证据。

**给 `<script>` 打 `data-` 标记或挪到别处。** 否掉：为了仪器好读去改生产标记，因果反了。

**干脆不迁内联脚本。** 否掉：F2 的目的是页面生命周期，不是省事；而且假差异是仪器的问题，换一种写法只是换一种撞法。

**维护一份「允许差异」清单。** 否掉：清单会随每次结构性改动膨胀，最后没人看，等于把判据改成人工裁量。

**只在 `diff` 输出里按标签名过滤日志。** 否掉：那只是不打印，差异计数照样红。

## 代价与边界

- 六类之外任何标签的增删仍然报红；这条口径不解释为「结构性改动都可以放过」。
- 不渲染元素行不参与比对，但**少写它们照样判「不完整」**（与 [ADR 0013](0013-style-audit-artifact-version.md) 的完整性校验同一条链）。
- 首页 `nth-child` 随机配色那条差异不由本 ADR 处理，仍走工具既有的 `dropBg` 一档。
- 剔除发生在归一化之后、比对之前，所以「同一端口」之类的归一化行为不受影响。

## 守卫在哪

- 往 `NON_RENDERING_TAGS` 里加标签前先回答「这个标签会不会生成盒子」。会，就不能加。
- 改这个集合必须同步 `scripts/lib/style-nonrendering.test.mjs` 的期望集合，并重跑六行变异矩阵；否则等于悄悄放宽判据。
- `tagOfLine` 只认行首标签名（含 `:hover ` 这类状态前缀），别改成「行里出现过就算」——那会把属性值里的标签名也吃进来。

## 落地状态（2026-11-12）

实现于 `91a5255`。新增 `scripts/lib/style-nonrendering.mjs`（判定 + 剔除，`stripNonRenderingLines` 返回保留行与被剔除条数）与 16 条单测；`scripts/upgrade-style-audit.mjs` 的 `load()` 在完整性校验之后、比对之前调用它。证据目录 `output/architecture-2026-11-10/F1-instrument/`（git-ignored）。

### 实测结果

- **同一对真实 artifact 复跑**：修复前 `exit 1`、12/23 页、2,365 条；修复后 `exit 0`、0/23 页、0 条，汇总行注明两侧各剔除 199 / 181 条。
- **变异矩阵**（最后一列是同一份脚本**只把剔除那步关掉**的对照版，用来证明补丁只改了它该改的那一处）：

    | 变异                                     | 补丁版                   | 对照版（不剔除）        |
    | ---------------------------------------- | ------------------------ | ----------------------- |
    | 删掉全部不渲染元素行                     | `exit 0`、0/23           | `exit 1`、23/23、181 条 |
    | 删一条渲染元素（`article.post-list`）    | `exit 1`、1 页、1 条     | `exit 1`、1 页、1 条    |
    | 加一条渲染元素                           | `exit 1`、1 页、1 条     | `exit 1`、1 页、1 条    |
    | 改一处渲染元素 `color`                   | `exit 1`、1 页、1 条     | `exit 1`、1 页、1 条    |
    | 改一条 `:hover` 状态行 `color`           | `exit 1`、1 页、1 条     | `exit 1`、1 页、1 条    |
    | 删不渲染行 **且** 改一处渲染元素 `color` | `exit 1`、1 页、**1 条** | `exit 1`、23/23、182 条 |

    结论：凡是渲染元素的增删或样式改动，两版判定逐项相同；差别只出现在涉及不渲染元素的用例上，合并用例从 182 条降到 1 条——既没放过真差异，也没让真差异被噪声淹没。

- **真实 CSS 变异**（改产物 CSS 再全量重采，不是改 artifact）：往 `dist/_astro/MainGridLayout.wWwsudvT.css` 追加 `article.post-list{padding-left:37px!important;}`，先在浏览器确认首页 10 个 `article.post-list` 的计算值都是 37px，再采集，采完立即恢复（sha256 与备份一致）。补丁版与对照版**都**是 `exit 1`、2/23 页、160 条，逐项相同。
- **同码自等**：同一份 `dist/` 连采两次，正文 23/23 逐字节相同；补丁版 `diff` 是 0/23，**关掉剔除的对照版同样是 0/23**——自等不是补丁造出来的。
- **完整性没被绕过**：把某页正文截掉一行、manifest 不动 → `exit 1`，报「正文实际行数不符」「正文摘要与 manifest 不符」「disabled 采样 60 → 59」，在样式比较之前就退出。
