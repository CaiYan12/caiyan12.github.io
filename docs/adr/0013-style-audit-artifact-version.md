# 0013：样式指纹 artifact 自带格式版本，旧采集与不完整采集一律拒绝

## 背景

样式指纹（`scripts/upgrade-style-audit.mjs`）是「这轮改动没有造成可见样式变化」这句话的唯一测量仪：`capture` 抓四态计算样式落盘成 artifact，`diff` 读两份 artifact 逐页逐元素比。旧格式只有 gzip 正文加一个 `index.json`，字段是 `{base, generated, pages}`，每页 `{path, slug, elements, sha, errors}`——没有格式版本，没有四态覆盖信息，没有完整性标记。

于是采集失败在产物上不留痕迹：`capture` 里 CDP 初始化抛错被空 `catch` 吞掉，产出的 artifact 与完整采集长得一模一样。这不是推演出来的风险，2026-11-10 用 HEAD 版脚本实测：CDP 一失败仍然 `EXIT=0`，23 页只剩 17,662 行（正好是静态行数，4×1,220 条状态行凭空消失），manifest 字段与完整采集同形；把它复制一份与自身 diff，得 `0/23`、0 条。同一份里只要一侧完整一侧失败，才报出 `23/23` 页、4,880 条差异。

**失败只有在单侧时看得见**，这正是「没测到」被当成「没变化」的入口。本批后面四个阶段的所有「UI 没变」结论都建立在这台仪器上，仪器本身必须先能自证。

## 决定

**一、artifact 有唯一格式版本 `style-audit-artifact@1`。** 没有版本、版本不符、或索引根本读不到，一律归为「旧格式」，拒绝并要求重新采集。不猜测、不静默兼容。

**二、manifest 不自证。** 每次读取都从正文重算四样东西——总行数、静态行数、四态各自计数、sha256 前 16 位——任何一项与 manifest 记的不符即判「不完整」。

**三、三种结果写死中文：`完整` / `不完整` / `旧格式`**（`ARTIFACT_STATUS`）。调用方比常量，不写字面量，也不从布尔量反推状态。

**四、写入端与读取端共用同一套每页判定**（`pageProblems`），「写的时候认为完整」与「读的时候认为完整」是同一个定义。四态计数只由落盘正文数出，不接受调用方传入。

**五、`diff` 的顺序固定：先验两侧 artifact，再比覆盖，最后才比样式。** 覆盖比较看页集合、每页目标元素数、每页每种状态的采样行数。任一环不过就 `exit 1`——「没采到」与「没变化」在输出上必须长得不一样。

**六、这次只加声明，不动判据。** 行内格式（`<标识> | <位置路径> | <属性…>`、`:hover …`）、四态集合、`STATE_MAX`、审计页清单、可见性分类与阈值一律未改。

## 被否掉的方案及理由

**兼容旧 artifact（缺字段按默认值补齐）。** 否掉：缺的恰好是「有没有采到」这个信息，补默认值等于替它编一个答案，而它会以「完整」的身份进入结论。

**只在 `diff` 端校验。** 否掉：`capture` 仍能写出坏产物，坏产物会被留档、被别人当成证据用。

**manifest 记录调用方传进来的计数。** 否掉：自证。计数必须从落盘正文数出来。

**版本做成可选字段。** 否掉：可选就等于永不生效——历史采集永远缺它，而历史采集正是要比的那一侧。

**顺手把 gzip 正文改成 JSON。** 否掉：行内格式是 A/B 可比性的基础，改它会让 2026-11-10 之前的采集全部作废，收益只是好读一点。

## 代价与边界

- **旧采集永久作废**：2026-11-10 之前采的所有 artifact 都不能再参与 `diff`（实测直接 `exit 1`）。
- **`targets` / `located` 仍然无法自证**：这两个数由 `capture` 的 Playwright 循环给出。module 能查的是「`targets` 是否等于 `located`」「四态计数是否等于 `located`」，查不了「这个数字是不是真量到的」。这是本 ADR 明确没有解决的部分。
- **`stateError` 只截前 160 字符**：够定位，不是完整堆栈。
- **版本一变两侧都得重采**：「拿旧采集比新采集」不再是可选项，这是故意的。

## 守卫在哪

- 改正文格式或 manifest 语义时**必须**同步改 `ARTIFACT_FORMAT`（`scripts/lib/style-audit-artifact.mjs`），否则旧采集会被当成新采集读进来。
- `elements` 是**行数**（含四态行），不是元素个数；静态行看 `staticLines`。
- 别把 `status` 换成布尔：`不完整` 与 `旧格式` 的处置不同——前者修采集，后者重采。

## 落地状态（2026-11-12）

实现于 `91a5255`。新增 `scripts/lib/style-audit-artifact.mjs`（356 行，写入器 / 读取校验 / 覆盖比较三件事）与 11 条契约测试；`scripts/upgrade-style-audit.mjs` 的 `capture` 改为逐页经 module 写入，`load` / `diff` 改为先校验再比。证据目录 `output/architecture-2026-11-10/F1/`（git-ignored）。

### 实测结果

- **同 dist 连采两次**：各 23 页 / 22,542 行（静态 17,662 + 四态各 1,220），两侧 `complete:true`、`problems: []`；`diff` 得 `0/23`、0 条、退出码 0。
- **旧↔新正文 23/23 逐字节相同**：这次加的是声明，不是数据；`gzip` 正文一行没变。
- **旧格式显式拒绝**：读 2026-11-10 之前采的 artifact，`exit 1`，提示「artifact 索引里没有格式版本，当前工具只认 style-audit-artifact@1」。
- **变异五组**（`diff-mut-hover` / `diff-mut-version` / `diff-mut-asym` / `diff-mut-manifest` / `capture-mut-cdp`）退出码全为 1；CDP 变异恢复后脚本 sha256 与变异前一致、无残留。
