# Nice Books · 私人藏书桌

2026-09-07 已批准设计方向，实施与验收进度见 [升级计划](plans/2026-09-07-nice-books-design-upgrade.md)。本说明替代原型 handoff §5–§8 的固定视觉参数及旧克制动效限制，不替代数据、路由和独立壳契约。

## 三层设计语言

- 环境：暖纸背景、墨色文字、印章红行动、蓝色链接；布局像整理好的私人书桌，装饰服从内容。
- 物件：四套原创 SVG 封面置于独立 Surface；Book3D 复刻 [Shano Murphy 的 CSS 3D book](https://codepen.io/shanomurphy/pen/xxqVdxM) 框架：前封位于 `+thickness`，后封位于 `-thickness`，右侧白色书口宽 `2 × thickness` 并绕 Y 轴 90°，整书以 −25° Y 轴视角展示。精选腰封贴在前封纸面，只绕过前封硬壳右缘形成窄折边，不覆盖书页；普通书保留裸封。
- 动作：主书换书像取出和放下；日常检索及时响应，移动端和减少动态效果模式保持操作直达。

## 字体与组件

正文使用现有思源黑体，标题及封面使用书宋，荐语/摘抄使用短手写文字，编号使用等宽字体。所有基础值收敛在 `--nb-*` token，Tailwind 继续使用 v3 的 `nb.` 命名空间。辅助文字至少13px，实际背景上的文字对比度至少4.5:1。可交互元素提供可见焦点与足够触摸区域。

四类封面使用独立展示配置按 ID 确定，不增加 Book 领域字段：文学以字为主；历史人文使用档案标签和结构线；科幻科普使用几何轨迹；散文随笔使用留白与抽象地景。无配置时回退文学。真实封面完整显示，加载失败仍生成同一书籍的 SVG。腰封仅使用真实现有荐语，不添加销售、获奖或阅读频率断言。

## Book3D 几何与 Surface 边界

- `lib/book-geometry.ts` 是三档书型的几何单一真相源，输出 `--book-*`、`--board-*`、`--page-*` 与 `--obi-*` CSS Variables；`depth` 对应参考实现的 `book-thickness`，书口和书脊宽度恒为 `2 × depth`。
- `render.ts` 保持 SSR 与客户端重渲染的标记单源，结构为 `Book3D → object → FrontBoard / BackBoard / SpineBody / PageTop / PageForeEdge / PageBottom / Obi`。书页面是旋转容器的直接子面，不为单本书设置坐标；后封和书脊颜色由封面主色派生。
- `hover` 只在精确指针上把 Y 轴从 −25°展开到 −30°～−32°并轻抬；减少动态效果时保持静态 −25°，不触发位移。
- 主书前封右上使用与详情页右侧相同的印章红燕尾书签，位于腰封同一前封 Surface；不再使用伸出书本顶部的半透明胶带。
- `.nb-front-artwork` 内继续接受现有 SVG、真实图片、HTML、普通 CSS 与 Tailwind 排版；它不承担硬壳厚度、页块内缩或书脊闭合。
- 禁止恢复 `--depth-x/y` 屏幕错位、`spine::before` 补面、背封扩宽遮挡、腰封跨越整个书口或固定负偏移等旧实现。

## 页面与状态

- 首页：主书与荐语构成视觉中心，保留随机单本与六本推荐。
- 书库：搜索、标签、双视图与结果构成一条清晰操作顺序；失败可重试，URL 查询保持。
- 详情：桌面双栏；手机先看到书名作者，再看到适度缩小的封面。荐语标题只出现一次。
- 网格：<360px单列，360–759px两列，>=760px三列；同架图书>=1080px四列。
- 换书：两个今日入口共享忙碌状态，动作结束才恢复。搜索输入不重播入场；标签、视图变化允许新操作接管。

## 技术约束

共享 render 字符串构造器同时服务 SSR 与客户端；独立壳与 Book/data.json/访问级随机/Pagefind 忽略语义保持。GSAP仅用于 books 主书时间线，其余反馈CSS/原生动画。页面替换前统一取消活动动画、请求与延时，初始化仍经共享入口和 `astro:page-load`。浏览器减少动态效果时取消位移、倾斜和级联延时；hover仅在精确指针生效。无 WebGL、滚动劫持或常驻漂浮。
