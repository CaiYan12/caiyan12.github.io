## What to build

Tailwind v4 引入了**真实的 CSS 级联层**，这推翻了仓库里一条被写进构建文档、供后续所有会话依赖的承重结论：「Tailwind v3 的 `@layer` 是构建期指令，产物里根本不存在 `@layer`，冲突按『特异性 → 源顺序』判定」。

它对 v3 成立，但 v4 不再成立，而且**依赖旧结论做出的样式决策会开始错**。本工单实测已经撞上这个问题的实体：typography 插件的正文排版规则落在工具类层，压过站点样式层里的 28 条正文规则——正文标题从 24px 变 36px、段落从 14px 变 16px、链接从品牌绿变插件蓝且失去下划线、全部 margin 归零。

解法是把站点的样式规则从 `@layer` 里移出，让它们以层外身份参与级联。CSS 级联规范规定层外的普通声明排在所有层内普通声明之后，因此站点规则恒胜，**精确还原 v3 靠「特异性 + 源顺序」得到的结果**。

同时补齐四处因 v4 语义变化而必须显式声明的补偿——它们若不写死就会静默变化：

1. **正文链接的下划线**：v3 靠 typography 插件的规则胜出；v4 的层序让层外的「链接无下划线」规则排到最后。
2. **正文列表项的左缩进**：v3 的缩进来自 typography 插件的 `.prose :where(ul > li){padding-inline-start:.375em}`（**补记（2026-11-04 实施时纠正）**：本条原先写「浏览器默认的内边距、实测 5.25px」，取错了基准——真实来源是插件那条 em 相对值，正文 13px 下实测计算值 **4.875px**）；v4 的预检把内边距归零。显式复刻同一个 em 相对值。
3. **表单控件的白底**：v3 的预检给表单控件设白底；v4 改为透明，而站内搜索框自身没有背景声明，会在浅灰页面底上露出底色。自带背景的控件由各自规则覆盖，不受影响。
4. **一处装饰符号的行高**：v4 把字号工具类的行高从**绝对长度**改成**比值**，继承到使用 em 相对字号的子元素时会按子元素字号重算（20px→17px），混排行盒少 1px，导致书库页文档高度变化 1px、其后内容整体上移。须写绝对行高——**不能用 `inherit` 修**（继承的是比值不是计算值，实测无效）。

工单完成后的状态：站点的样式覆盖关系重新变成「可推理的」——因为站点规则恒胜，覆盖顺序由源文件顺序唯一确定，不再需要在层序与特异性之间做心算。

## 完成记录（2026-11-04）

提交 `9543a59`（移出层 + 补偿）、`534f3b6`（两处可见回归修复与补偿值纠正）、`01836a9`（光标规则归位）。

**「移出所有层」有三处按属性正面清单的例外，必须留在 `@layer base`**——它们声明了 Tailwind 也声明的属性（`padding`/`margin`/`cursor`/`background-color`/`outline`/`border-radius`），留在层外会反过来压过 utility：

1. `body,div,…,input,textarea{…}` —— 否则 `/search/` 的 `px-3` 变 0
2. 可点元素的 `cursor` —— 否则 `disabled:cursor-not-allowed` 失效
3. `input,textarea{background-color:#fff}` —— 否则搜索框露灰底
   （外加 `books.css` 的 `:focus-visible`，否则压掉 `rounded-[3px]` 与 `outline-none`）

**补偿实际为五处**，写在验收标准里的「四处」是实施前的估计：

- `.prose a` 补 `text-decoration: underline`
- `.prose li` 补 `padding-inline-start: 0.375em`（复刻 typography 插件的 **em 相对值**，不是写死 4.875px；正文 13px 下实测计算值 4.875px）
- `input,textarea` 补 `background-color:#fff`
- `books/index.astro` 的 span 补 `leading-[20px]`（v4 把 `text-sm` 行高从绝对值改为比值）
- `books/index.astro` 的简介段落补 `max-[540px]:leading-[1.5rem]`（**走到移动视口验收才发现**：v4 字号工具类行高走 `var(--tw-leading)`，只要带 `leading-*` 就由它决定，移动端行高会从 24px 变 35.2px、整页 +42px）

验收：23 页指纹可见差异 0 条；关键计算值 12 页全部一致（含 `/books/` 文档高度 2223、文章页 6197）。
