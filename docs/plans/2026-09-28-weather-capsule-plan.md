## 一、实现边界与已核实入口

- 主站侧栏由 `src/config.ts` 的 `sidebarConfig.widgets` 通过 `src/components/layout/SideBar.astro` 发射；`blogger` 即「吐槽水军」，新天气项须排在它之前。小部件视觉沿用 `src/components/widget/WidgetLayout.astro` 与 `.widget` 的有边框、直角样式。

- `/domain/` 是 ADR 0002 锁定的独立壳。当前 `src/domain.html` 的初始「天气加载中…」在脚本未加载时会常驻；`public/domain/js/weather.js` 使用未粗化坐标，定位失败按 IP 回退 wttr.in。票 01 先把这条现存路径修到真实、可恢复。
- 现有 `scripts/lib/smoke-harness.mjs` 与 `pnpm smoke:ui` 提供真实浏览器外部验收缝隙；新增天气判据复用其结果、console/pageerror 收集模式。离线服务测试仅在最高可用 `fetchImpl` 缝隙注入响应。
- 和风账号、专属 API Host、API KEY 的本机只读鉴权已验证；生产代理与大陆直连链路尚未验证。API KEY 只在本机 DPAPI 凭据与未来代理 secret 中使用，任何 issue、文档、命令输出、构建产物都不得含真实值。
